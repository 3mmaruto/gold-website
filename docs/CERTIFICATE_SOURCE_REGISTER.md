# Manufacturer Document Source Register

## Purpose

This public register records only the manufacturer documents approved for publication on the website. The complete internal source audit remains with the private source material outside this public repository.

Public presentation must remain scope-specific:

- these are documents naming HONMOOK / Hanmook Technology (Guangdong) as manufacturer, applicant, patent holder, or component manufacturer;
- they are not certificates issued to Gold Group;
- a patent certificate is not a product-conformity certificate;
- an incomplete report cover is not presented as a complete test report;
- expired documents and documents outside the current heat-pump scope are not published as current evidence;
- the original-language PDF is authoritative.

## Publication rule

Future additions require a complete, readable source document with:

1. the issuing authority or laboratory;
2. the named holder/applicant/manufacturer;
3. the exact product or technical scope;
4. the document/report/certificate number;
5. issue and validity dates where applicable;
6. all referenced pages, model lists, signatures and appended certificates for conformity or test-report claims;
7. if a patent-certificate continuation page is missing, the public UI must label the file as a manufacturer-supplied first-page scan and must not describe it as a complete record;
8. an approved public PDF slug and SHA-256 recorded here.
